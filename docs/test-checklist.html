★ What we built — to explain to your customer

A plain-language summary of everything delivered. Pulse is a multi-tenant AI-agent platform; this round made it enterprise-ready.

🛡️ Enterprise security & compliance

  • Audit log — every admin action is recorded (who did what, when, from where) and exportable to CSV. Answers the first question on any security review.
  • Role-based access control — granular roles (Owner / Admin / Support / Auditor for staff; Owner / Member / Viewer per workspace). People only see and do what their role allows, enforced on the server.
  • Single Sign-On (SSO) — staff sign in with the company's own identity provider (Okta / Microsoft / Google). IT controls access centrally; disable someone there and they lose access instantly.
  • Two-factor authentication (2FA) — optional per-user login codes via an authenticator app.
  • Signed plugin approvals — plugins must declare exactly what they can access, and an admin approves it. If a plugin update changes its powers, it's automatically disabled until re-approved (blocks supply-chain surprises).
  • All secrets encrypted at rest; every workspace's data isolated from every other.

🎨 Complete admin redesign

  • Rebuilt the entire admin console into a modern, consistent interface — a real operations command center with revenue/margin, live platform activity, workspace & user management, and honest system-health.
  • Full light & dark mode with a one-click toggle, and one unified design system so every page looks and behaves the same.

✉️ Accounts & email

  • Forgot-password and user-invitation emails; SMTP configured in-app (no code needed).

⚙️ Reliability & operations

  • Fixed a production outage and added a self-healing watchdog + auto-restart so the platform recovers on its own.
  • Automated database backups; a versioned release & deploy process.

🤖 Core platform (already in place, now hardened)

  • AI agents over Telegram & email, multi-provider (Anthropic / OpenAI / Google / others), credit billing with per-model cost/margin, usage analytics, conversation history, scheduling, agent memory, and a plugin system (e.g. ERPNext).
